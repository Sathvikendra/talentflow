# talentflow
Talent recruitment for a specific client with human-approved resume shortlisting and automated interview scheduling.

============================================

TalentFlow

AI-Assisted Talent Fulfillment and Candidate Workflow Platform

TalentFlow is a portfolio project that demonstrates full-stack development,
workflow management, authentication, AI-assisted resume analysis,
dashboard analytics, and enterprise-style application architecture.

Technology Stack

Frontend
- Angular 22
- TypeScript
- Angular Material
- SCSS
- RxJS

Backend
- Java 21
- Spring Boot 4.x
- Spring Security
- JWT
- Spring Data JPA
- Hibernate
- Maven

Database
- MySQL
- Flyway

AI
- Gemini API

Document Processing
- Apache PDFBox
